# Project 9: Hemilineage prediction (lock note repository)

Machine Learning, Section 2. This repository supports the lock note. **No model has been run on the connectome.**


## Reproduce
1. Run the course data kit so `data/course/` exists (the data is not stored in this repository).
2. `pip install -r requirements.txt`
3. `python first_look.py data/course` (or run `first_look.ipynb`)
4. `pytest -v` runs all code checks.
